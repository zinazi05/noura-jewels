
# Noura Jewels – E-commerce Web Application

## 1. Student Information
- **Student Name:** Zineb Ziane
- **Application Name:** Noura Jewels

## 2. Application Description

Noura Jewels is an e-commerce web application dedicated to showcasing and selling traditional and contemporary Algerian jewelry.

The application provides users with an elegant shopping experience where they can browse jewelry collections, explore product details, filter products, add items to their shopping bag, and proceed to checkout.

## 3. Technologies Used

- React.js 
- Vite 
- JavaScript 
- HTML5 
- CSS3 
- Tailwind CSS 
- Redux

## 4. Main React Components

The main components of the application include:

- **Header:** Navigation menu and shopping bag access.
- **Home:** Main landing page and featured collections.
- **Shop:** Displays the available jewelry products.
- **CategoryFilter:** Filters products by category and other criteria.
- **ProductCard:** Displays product images, names, and prices.
- **ProductDetails:** Shows detailed information about a selected product.
- **ShoppingBag:** Displays selected products and quantities.
- **Checkout:** Handles customer and delivery information.
- **Footer:** Displays navigation and contact information.

## 5. Redux State Managed by the Application

The application state may include:

- **Products State:** Stores available jewelry products.
- **Filters State:** Manages selected categories, materials, and price filters.
- **Cart State:** Stores selected products, quantities, and cart totals.
- **UI State:** Manages shared interface states.

## 6. Implemented Features

- Homepage showcasing jewelry collections.
- Product catalog with images and prices.
- Product categorization and filtering.
- Product details page.
- Add products to the shopping bag.
- Update product quantities.
- Remove products from the shopping bag.
- Automatic subtotal calculation.
- Checkout interface.
- Order confirmation page.
- About Us and Contact sections.
- Responsive user interface.

### Step 1: Install Dependencies

Open the project folder in the terminal and execute: 
npm install

### Step 2: Start the Development Server

Run the following command:
npm run dev

### Step 3: Open the Application

Open the local URL displayed in the terminal, usually:
http://localhost:5173/

### Step 4: Build the Application

To generate the production build, execute:
npm run build
